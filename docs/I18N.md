# Локализация веб-консоли (RU / EN)

Консоль TAO — одностраничное приложение: `tam/web/index.html` собирается из
`index.src.html` + `styles.css` + `i18n.data.js` + `i18n.js` + `app.js` скриптом
`tam/web/build.py`. Исходный язык интерфейса — упрощённый китайский; русский и
английский подставляются на лету.

## Как это устроено

* `tam/web/i18n.js` — рантайм: словари, поиск перевода, обход DOM, `MutationObserver`,
  переключатель языка, тема.
* `tam/web/i18n.data.js` — **генерируемый** словарь (`window.__TAM_I18N__`), руками не правится.
* Перевод идёт **на уровне DOM**, поэтому `app.js` не переписан:
  * текстовые узлы → точное совпадение, затем шаблоны `%s`;
  * атрибуты `placeholder` / `title` / `alt` / `aria-label` / `value` (кнопки);
  * многострочные блоки (`<pre>` с логами) переводятся построчно;
  * всё, что приложение дорисовывает позже, ловит `MutationObserver`.
* Оригиналы запоминаются (`WeakMap`), поэтому переключение RU↔EN переводит заново,
  а не переводит перевод.
* Поиск перевода: точное совпадение → шаблон `%s` (длинные шаблоны первыми) → разбиение строки
  по ` · ` на сегменты. Захваченные группы шаблона переводятся **рекурсивно**, поэтому
  `5 分钟后` разворачивается через `%s 分钟后` → `%s 分钟` → `5 мин`.
* Китайский не ставит пробелов вокруг `<strong>`/`<code>` — рантайм добавляет пробел на границе
  текстового узла с инлайн-элементом, если с обеих сторон буквы/цифры (или `(`/`«`).
* Одиночные узлы-пунктуация (`、。，：；（）「」【】`) переводятся отдельной таблицей.
* Абзац с переносами сначала ищется целиком, и только потом переводится построчно (логи, сводки).
* Язык и тема хранятся в `localStorage` (`tam.lang`, `tam.theme`), тема по умолчанию —
  системная (`prefers-color-scheme`).
* Непереведённая строка остаётся на китайском — это безопасный фолбэк, а не ошибка.

## Пайплайн перевода

```bash
python3 tools/i18n_extract.py    # исходники -> tools/i18n_src.json + tools/i18n_batches/*.json
# ... перевод батчей (tools/i18n_out/batchNN.json) по tools/i18n_glossary.md ...
python3 tools/i18n_validate.py   # id, пустые значения, %s, остатки CJK
python3 tools/i18n_build.py      # -> tam/web/i18n.data.js
cd tam/web && python3 build.py   # -> tam/web/index.html (один файл, без сборщика)
systemctl --user restart tgcrm   # подхватить новую статику
```

Батч = массив `{"id","kind","zh"}`; `kind`:

| kind | что это | как переводить |
|------|---------|----------------|
| `frontend` | строки из `app.js` / `index.src.html` | как есть; HTML-разметку и `onclick` не трогать |
| `pattern` | шаблон с `%s` (интерполяция `${...}`) | столько же `%s`, в том же порядке |
| `backend` | описания инструментов, параметров, ошибки API | переводить текст вокруг `{expr}`, регулярки не трогать |

## Добавить перевод вручную

`tools/i18n_extra.json` — объект `{"<китайская строка>": {"ru": "...", "en": "..."}}`.
Ключ с `%s` автоматически становится шаблоном. Применяется поверх батчей — удобно
для строк, которых не было в исходниках (динамические сообщения сервера), для
контекстных омонимов и для исправления неудачных переводов. Примеры, которые уже там:
`"%s 分钟后"`, `"隐藏【%s】"`, `"监控 %s 个号"`, `"分钟": "мин"`.

Флаги стран (`🇷🇺` и т.п.) сборщик вырезает из значений: на машинах без emoji-шрифта
они превращаются в «тофу», а страна и так подписана.

## Проверка «китайского не осталось»

Открыть `http://127.0.0.1:8848`, пройтись по панелям и выполнить в консоли браузера:

```js
const cjk=/[\u4e00-\u9fff]/, out=new Set();
const w=document.createTreeWalker(document.body, NodeFilter.SHOW_TEXT);
for(let n; (n=w.nextNode());) if(n.nodeValue && cjk.test(n.nodeValue)) out.add(n.nodeValue.trim());
document.querySelectorAll('[placeholder],[title],[alt],[aria-label]').forEach(el=>
  ['placeholder','title','alt','aria-label'].forEach(a=>{const v=el.getAttribute(a);
    if(v && cjk.test(v)) out.add('@'+a+': '+v);}));
console.log(out.size, [...out]);
```

Пустой список — локализация полная.

## Тема

`[data-theme="dark"]` в `styles.css` переопределяет CSS-переменные (`--canvas`,
`--border`, `--blue`, …) и точечно — статусные цвета и тени. Кнопка в шапке
(`#themeBtn`) переключает светлую/тёмную и меняет иконку sun/moon.

## Иконки

Все иконки — инлайн-SVG из спрайта в начале `<body>` (`index.src.html`),
`<use href="#i-name">`. Эмодзи в интерфейсе не используются: на машинах без
CJK/emoji-шрифтов они превращаются в «тофу». Добавить иконку = добавить
`<symbol id="i-name">` в спрайт и вызвать `icon('i-name')` из JS или
`<svg class="ico"><use href="#i-name"/></svg>` из HTML.
